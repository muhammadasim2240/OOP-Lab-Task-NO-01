# OOP Assignment 01 – C++

## 📌 Project Overview

This repository contains **OOP Assignment 01** developed in **C++**.

The assignment focuses on basic **Object-Oriented Programming concepts**, including:

* Classes and Objects
* Private Data Members
* Public Member Functions
* Data Encapsulation
* `setData()` Function
* `display()` Function

## 📂 Questions Covered

### Q1 – BankAccount

A `BankAccount` class is created with the following private data members:

* `accountNumber`
* `accountHolder`
* `balance`

The `setData()` function is used to store account information, while the `display()` function shows the stored information.

Example data:

```text
Account Number: 101
Account Holder: Ali
Balance: 50000
```

### Q2 – Student

A `Student` class is created with the following private data members:

* `studentID`
* `studentName`
* `department`
* `semester`

The `setData()` function stores student information, and the `display()` function displays the information.

Example data:

```text
Student ID: 101
Student Name: Ali
Department: Computer Science
Semester: 3
```
